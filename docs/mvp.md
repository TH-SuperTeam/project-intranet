Stack:  
**TypeScript, Java, Spring, React, MySQL**  
Vi vill öva mer på det som är nyast för oss (TypeScript, React, Spring), samt kopplingen mellan frontend och backend till både ett eget och externt API.

Funktioner:  
Inloggning/Security  
Fler-rolls-perspektiv (admin och user)  
Karta-API  
eventuellt andra Externa APIer

Nice to have:  
Tester

Projektidé:  
Ett intranät för personal samt studerande på Teknikhögskolan. Innehåller dashboard (anpassad utifrån roll \- admin, anställd, student) som visar tex nyheter, närliggade restauranger, kollektivtrafik, väder. En profil för att ändra personliga uppgifter.

| Funktion | Prioritet | Varför? |
| ----- | ----- | ----- |
| Inloggning och roller | Måste | Vårr viktigaste säkerhetsfunktion |
| Personlig dashboard | Måste | Produktens kärna |
| Nyhetsflöde per roll | Måste | Tydlig affärslogik |
| Admin kan publicera nyheter | Måste | Fullständigt arbetsflöde |
