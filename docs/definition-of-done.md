
# Definition of Done

1. Alla acceptanskriterier är uppfyllda och testade för hand.
2. When applicable: Layouten ska anpassas automatiskt efter skärmens storlek.
3. Koden ligger i **dev** via en pull request.
4. Pull requesten är granskad och godkänd av minst en annan i teamet.
5. Applikationen startar och körs utan fel efter mergen.
6. Det finns inga `console.log`, utkommenterad kod eller `TODO` kvar i ändringen.
7. Kortet på boarden är flyttat till **"Klart"**.
8. `README.md` eller `docs/` är uppdaterad om ändringen påverkar hur man startar eller använder projektet.
